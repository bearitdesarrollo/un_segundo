# Splash

Pon tu imagen de splash aquí:

- Archivo: `assets/splash/splash.png`
- Tamaño recomendado: **1080x1920 px** (o 1152x1152 logo centrado con fondo transparente)
- Fondo: se configura en `flutter_native_splash.yaml` como `color: "#040F23"` (azul eléctrico oscuro)

Opcional logo centrado: `assets/splash/logo.png` 512x512
