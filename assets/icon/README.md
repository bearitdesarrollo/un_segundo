# Icono

Pon tu icono aquí:

- Archivo: `assets/icon/app_icon.png`
- Tamaño: **1024x1024 px**, PNG sin transparencia (fondo sólido), centrado
- El script genera automáticamente los mipmap Android

No pongas el icono directamente en `android/app/src/main/res/mipmap-*` — se sobrescribirá al ejecutar el generador.
